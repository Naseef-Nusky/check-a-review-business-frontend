# Check A Business Frontend

React + Vite + Tailwind business portal for **Check A Review**.

## Run

```bash
cd check-a-business-frontend
npm install
npm run dev
```

App runs at **http://localhost:5175**

## Routes

| Path | Description |
|------|-------------|
| `/login` | Business login |
| `/setup` | Business account setup |
| `/` | Dashboard (protected) |
| `/profile` | Company profile |
| `/reviews` | Reviews |
| `/invitations` | Invitations |
| `/analytics` | Analytics |
| `/widget` | Embed widget |
| `/settings` | Settings |

API proxy targets `http://localhost:5000`.
